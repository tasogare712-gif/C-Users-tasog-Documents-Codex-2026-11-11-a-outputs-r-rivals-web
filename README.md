# R-Rivals

スマートフォン縦向き対応の無料ブラウザカードゲームです。

- CPU対戦
- 同じ端末で2人対戦
- 別々の端末から部屋コードで接続するオンライン対戦

## オンライン対戦

1. 両方の端末で https://r-rivals.onrender.com/ を開き、「オンライン」を選びます。
2. ホスト側が「対戦部屋を作る」を押し、表示された5文字の部屋コードを相手に伝えます。
3. 相手側は部屋コードを入力し、「コードで参加」を押します。
4. 接続できたら、ホストが「対戦を始める」を押します。

各プレイヤーが自分の端末からカードを選びます。オンライン接続にはPeerJSの無料シグナリングサービスを利用します。ネットワークによって接続できない場合は、Wi-Fiとモバイル回線を切り替えて再度お試しください。

## PCで起動

```powershell
npm install
npm run dev
```

## 公開

現在の公開先は https://r-rivals.onrender.com/ です。GitHubの`main`ブランチに変更を保存するとRenderが自動で再デプロイします。
